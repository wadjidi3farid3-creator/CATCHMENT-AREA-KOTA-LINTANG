GITHUB EARTH PACKAGE
===================

Nama Paket:
terpadu_GITHUB

File:
- index.html
- terpadu.kml
- terpadu.kmz
- manifest.json
- README.txt

CARA UPLOAD:
1. Upload seluruh isi folder paket ke repository GitHub.
2. Pastikan index.html berada pada root folder yang dipublikasikan.
3. Aktifkan GitHub Pages.
4. Buka link GitHub Pages.

LINK GOOGLE EARTH WEB:
https://earth.google.com/web/@4.2835910,98.0659280,1000a,1000d,35y,0h,0t,0r

CATATAN:
Link Google Earth Web diarahkan ke koordinat
titik tengah data KML.

Link KMZ merupakan file peta yang dapat diunduh
dan dibuka melalui aplikasi yang mendukung KMZ,
termasuk Google Earth jika tersedia pada perangkat.
